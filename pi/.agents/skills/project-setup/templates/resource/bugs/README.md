# resource/bugs

Defects this codebase produced, separated from `resource/lessons/`.

## The split rule

- A bug is something this codebase did wrong. It goes here.
- A lesson is something the outside world does: a platform, library,
  machine, or environment behavior. It stays in `resource/lessons/`.

## Naming

- `edge.<YYYYMMDD>.<title>.md` — a bug the happy path missed.
- `regression.<YYYYMMDD>.<title>.md` — a bug that came back after
  being fixed.

## Shape

Same sections as a lesson: what happened, why it happened, the fix,
and the rule that falls out of it. Filed before the fix is committed.
