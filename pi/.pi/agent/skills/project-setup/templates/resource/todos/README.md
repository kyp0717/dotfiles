# Todos

Open tasks and reminders not tied to one session's work. Handoff covers
session continuation; everything else that must not be forgotten lives
here.

Agents:

- Write every open task here before ending a session. In-chat task
  lists die with the session.
- One file per topic, named `YYYYMMDD-<topic>.md` (match the project's
  existing date style if it differs).
- Scan this folder at session start, after reading handoff.
- Retire a unit when its items are done; never append forever.
